## محاسباتی که بررسی و تایید شد (بدون خطا)

- **قابل وصول = جمع اقلام (یا برآورد) − پرداخت‌شده (بیعانه + مابقی)** — با تست عددی تایید شد: برآورد ۵۰۰٬۰۰۰ − بیعانه ۱۰۰٬۰۰۰ = ۴۰۰٬۰۰۰ ✓
- **مبلغ افزوده نسبت به برآورد اولیه** فقط وقتی جمع اقلام از برآورد بیشتر باشد ✓
- **ذخیره اعداد:** ورود فارسی/انگلیسی هر دو → ذخیره انگلیسی در بانک (`toEnglishDigits` قبل از parse در همه فیلدهای عددی) ✓
- **تاریخ شمسی:** سال کبیسه ۱۴۰۳ اسفند ۳۰ روز و ۱۴۰۴ اسفند ۲۹ روز با کتابخانه shamsi_date تایید شد ✓
- **کد سفارش:** ترتیب RCP-YYYYMMDD-### بر اساس شمارنده روزانه، بدون تکرار ✓
- **صف ایمیل:** تا ۲۰ تلاش، بعد وضعیت failed؛ سناریوی آفلاین تست شد (ارسال صفر، صف حفظ می‌شود) ✓
- **شمارنده نصب:** بیشینه سه منبع + آینه چهارم — ریست با پاک‌کردن بانک ناممکن است ✓

## پوشش تست اجرای واقعی
۱۶ تست (۳ ثابت + ۱۳ سرتاسری) شامل: ساخت بانک → ویزارد/صف گزارش نصب → پذیرش کامل → PDF واقعی → ICS → دستیار → بک‌آپ/بازیابی → سوپروایزر → پاک‌سازی کامل → ابزارهای شمسی. نتیجه: **All tests passed**.
