# داشبورد تعمیرات و خدمات — نسخه ۰.۱ (فاز ۱: هسته ویندوز)

سامانه مدیریت فروشگاه تعمیرات موبایل و لوازم الکتریکی — پروژه J.S.H برای شرکت **آورین سگال بی همتا**.

## ساخت پروژه (Windows)

پیش‌نیاز: [Flutter SDK](https://docs.flutter.dev/get-started/install/windows) + Visual Studio «Desktop development with C++».

```powershell
cd dashboard_app
flutter pub get
flutter run -d windows        # اجرا
flutter build windows         # خروجی Release
```

اسکلت پلتفرم `windows/` و `android/` همراه مخزن است و آیکون‌های لوگو داخل آن‌ها جایگزین شده‌اند؛ نیازی به `flutter create` نیست.

## ساخت APK (فاز ۳ — فعلاً اسکلت)

```powershell
flutter build apk --release
```

## تست گام‌به‌گام برای صاحب پروژه

1. `flutter run -d windows` — برنامه ویزارد راه‌اندازی را نشان می‌دهد.
2. در گام مجوز، تیک پذیرش را بزنید؛ ایمیل جیمیل + رمز برنامه (App Password گوگل) وارد کنید.
3. اطلاعات فروشگاه را ویرایش یا تایید کنید؛ یادآوری ۳ روز + ساعت ۹ را انتخاب کنید؛ ثبت نهایی.
4. اگر اینترنت باشد: گزارش فعال‌سازی به ایمیل سازنده می‌رود و برنامه باز می‌شود.
5. اگر اینترنت نباشد: صفحه انتظار می‌آید و با وصل شدن اینترنت به‌صورت خودکار ارسال و باز می‌شود.
6. مشتری بسازید، دستگاه پذیرش کنید، امضا بکشید → PDF رسید ساخته و ایمیل + رویداد تقویم در صف قرار می‌گیرد.
7. در کارتابل سفارش را تا «آماده تحویل» جلو ببرید؛ در صفحه یادآوری‌ها بیعانه/مبلغ افزوده/قابل وصول را ببینید.

> نکته امنیتی: رمز برنامه جیمیل فقط در بانک محلی دستگاه ذخیره می‌شود و فقط برای ارسال از همان ایمیل استفاده می‌شود.

## بازطراحی مدرن نسخه ۰.۳ + فاز ۲
- **۳ تم پیش‌فرض** (تیره مدرن / روشن کلاسیک / کرمی طلایی) با سوئیچ فوری — در نوار بالا یا نقطه‌های پایین سایدبار
- **ماژول «تم و ظاهر»:** شخصی‌سازی ریز — رنگ تاکیدی، گردی، اندازه متن، چگالی، انیمیشن‌ها، **فونت متن و فونت اعداد از فونت‌های ویندوز**، پیش‌نمایش زنده
- **فرمان shrink-to-fit سراسری:** هیچ متن/عددی با هیچ فونتی از کادر بیرون نمی‌زند
- **سایدبار شناور** با انیمیشن hover (باز/جمع خودکار) + منوی آبشاری «بخش‌ها» + ترنزیشن صفحات
- **نمودارها:** دونات وضعیت سفارش‌ها، خطی درآمد + **پیش‌بینی خط‌چین ۳ ماه** (میانگین متحرک — برآورد شفاف)، میله‌ای قابل وصول
- **DataTablePro:** سورت + جستجو + فیلتر هر ستون + مخفی/نمایش و تغییر عرض ستون‌ها (پایدار) + ارتفاع سطر از چگالی + جمع پویا
- **فاز ۲ — گارانتی:** ساخت خودکار هنگام تحویل، هشدار انقضا ۳۰ روز، تمدید یک‌کلیکی؛ دستیار: «گارانتی شماره X»، «گارانتی‌ها»، «پیش‌بینی فروش»
- اسکرین‌شات هر بخش در هر تم: `docs/screenshots/` (۲۷ تصویر رندر واقعی)
- تست: `flutter test` — ۴۵ تست سبز شامل ۲۷ تست golden
