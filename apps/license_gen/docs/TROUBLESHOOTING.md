# عیب‌یابی — مولد کد فعال‌سازی J.S.H

## الف) هنگام نصب/اجرا

| نشانه | علت | راه‌حل |
|---|---|---|
| `flutter: command not found` | Flutter در PATH نیست | نصب Flutter و افزودن `flutter\bin` به PATH؛ سپس باز کردن دوباره ترمینال |
| `flutter doctor` خطای Visual Studio | بار کاری C++ دسکتاپ نصب نیست | نصب «Visual Studio Build Tools» با بار کاری **Desktop development with C++** |
| `Windows desktop is not enabled` | پشتیبانی دسکتاپ خاموش است | `flutter config --enable-windows-desktop` |
| خطای `pub get` / دانلود بسته‌ها | اتصال به pub.dev ناپایدار | اتصال اینترنت را بررسی کنید؛ در صورت نیاز از mirror رسمی Dart استفاده کنید |
| exe ساخته می‌شود ولی باز نمی‌شود | DLLهای کنار exe منتقل نشده‌اند | **کل محتوای** پوشه `build\windows\x64\runner\Release\` را با هم کپی کنید |
| حروف فارسی به‌هم‌ریخته در CMD | انکودینگ کنسول | `chcp 65001` یا استفاده از Windows Terminal/PowerShell |

## ب) کد فعال‌سازی قبول نمی‌شود

ابتدا با ابزار خط فرمان ببینید پیام واقعی چیست:

```powershell
cd packages\activation_core
dart run example/make_code.dart --verify "<کد>" --device "<شناسه>"
```

| نتیجه بررسی | معنا | اقدام |
|---|---|---|
| `قالب کد نادرست است` | کد ناقص کپی شده یا حروف اضافه دارد | کد را کامل و دقیق از برنامه مولد کپی کنید؛ توجه: بدنه باید ۳۶ کاراکتر باشد (با/بدون `JSH-` فرق نمی‌کند) |
| `کد دستکاری شده است` | یک حرف تغییر کرده یا کد ساختگی است | کد را دوباره بسازید و مستقیم از برنامه کپی کنید |
| `کد مال دستگاه دیگری است` | شناسه ارسالی خریدار با دستگاهی که کد ساخته شده نمی‌خواند | از خریدار بخواهید شناسه را **دوباره** از صفحه فعال‌سازی کپی و ارسال کند؛ سپس کد جدید با شناسه درست بسازید |
| `اعتبار کد تمام شده` | تاریخ اعتبار گذشته | کد تمدید با تاریخ جدید بسازید |
| `نسخه کد با برنامه نمی‌خواند` | کد با هسته قدیمی ساخته شده ولی برنامه جدید دارد (یا برعکس) | هر دو برنامه را از یک نسخه مخزن بیلد کنید |

نکته: کد با/بدون خط‌تیره و با حروف کوچک/بزرگ فرقی نمی‌کند؛ `I,L→1` و `O→0` خودکار تصحیح می‌شود.

## ج) برنامه اصلی خریدار

| نشانه | معنا |
|---|---|
| «قبلاً N بار نصب شده و سهمیه به پایان رسیده» | شمارنده نصب به سقف ۳ رسیده — اگر نصب واقعی/تازه است، مشکل پشتیبانی برنامه اصلی را بررسی کنید |
| «اعتبار … به پایان رسیده» | انقضا؛ کد تمدید با همان شناسه بسازید |
| برنامه تاریخ را دستکاری‌شده اعلام می‌کند | تاریخ سیستم عقب برده شده؛ خریدار تاریخ درست بگذارد و برنامه را باز کند |
