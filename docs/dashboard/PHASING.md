# سند فازبندی نسخه ۲ — «داشبورد تعمیرات و خدمات»

**تاریخ:** ۱۴۰۵/۰۹/۰۴ — **وضعیت:** تایید صاحب پروژه؛ مبنای اجرا
> **به‌روزرسانی نسخه ۰.۲:** قواعد ۱-۱۲ صاحب پروژه پیاده و اعتبارسنجی شد — تقویم شمسی کامل + خروجی Google Calendar، جدول هوشمند (سورت/فیلتر/جمع)، دستیار آفلاین، مدیریت دیتابیس با بک‌آپ اتوماتیک و پاک‌سازی سوپروایزری، امنیت HMAC لایسنس، بازطراحی نوار hover + منوی آبشاری، حسابرسی با رفع ۶ خطا، ۱۶ تست سرتاسری سبز.
**قاعده طلایی:** در هر لحظه فقط یک فاز فعال است؛ فاز بعدی فقط پس از تحویل و تایید خروجی فاز فعلی شروع می‌شود. هر گام یک خروجی قابل تست دارد.

## فاز ۱ — هسته ویندوز (فعال) — ۶ هفته، ۶ گام

> **وضعیت فعلی (۱۴۰۵/۰۹/۰۴):** کد تمام ۶ گام در `apps/dashboard/` نوشته و اعتبارسنجی شد (flutter analyze بدون خطا، ۳ تست سبز). گام بعدی: build و تست واقعی روی ویندوز توسط صاحب پروژه.

| گام | محتوا | خروجی قابل تست |
|---|---|---|
| ۱.۱ (هفته ۱) | اسکلت پروژه Flutter + پایگاه‌داده SQLite + مدل‌ها + ریپازیتوری‌ها + پوسته RTL فارسی | برنامه روی ویندوز اجرا و بانک ساخته می‌شود |
| ۱.۲ (هفته ۲) | لایسنس: اثر انگشت سخت‌افزار، شمارنده نصب (حداکثر ۳)، قفل چهارم؛ ویزارد اول: مجوز ارسال + ایمیل کاربر معتبر + اطلاعات فروشگاه (پیش‌پر از اطلاعات سازنده) + تنظیمات یادآوری (۲/۳/۷ روز + ساعت) | نصب مجازی گزارش نصب می‌سازد؛ قفل‌ها کار می‌کنند |
| ۱.۳ (هفته ۲-۳) | گزارش نصب الزامی (N-03): ساخت payload سخت‌افزاری، صف آفلاین، تلاش مجدد، دروازه ۳۰ روزه و بستن راه‌اندازی تا ارسال موفق | با اینترنت ارسال می‌شود؛ بدون اینترنت صف و دروازه کار می‌کند |
| ۱.۴ (هفته ۳-۴) | CRM + پذیرش (فرم F-12-1): مشتری، دستگاه، چک‌لیست لوازم، بیعانه، امضا، رسید PDF با سربرگ | چرخه پذیرش کامل ثبت و PDF چاپ می‌شود |
| ۱.۵ (هفته ۴-۵) | کارتابل تعمیر (S-01) + فاکتور و پرداخت + بیعانه + ایمیل رسید + رویداد ICS | سفارش تا تحویل با ایمیل/تقویم تست می‌شود |
| ۱.۶ (هفته ۵-۶) | یادآوری (F-05 + N-01): موتور ۲/۳/۷ روزه با جزئیات مالی + نوتیف ویندوز + صفحه یادآوری‌ها + پشتیبانی (N-02) | یادآوری با تنظیمات کاربر صادر می‌شود |

**معیار پایان فاز ۱:** فروشگاه با این نسخه می‌تواند کل چرخه پذیرش تا تحویل را آفلاین انجام دهد و گزارش نصب به سازنده ارسال شده باشد.
