# مشخصات فنی برنامه J.S.H

> **وضعیت:** نسخه‌ی ۱.۰ — پیاده‌سازی کامل شده و تست شده است.

## ۱. نام و هدف

- **نام برنامه:** J.S.H
- **نوع برنامه:** دفترچه‌ی یادداشت شخصی، رابط خط فرمان (CLI)
- **هدف:** ثبت و مدیریت سریع یادداشت‌های شخصی با ذخیره‌سازی پایدار، تاریخ شمسی و بدون وابستگی خارجی.

## ۲. الزامات کارکردی (پیاده‌سازی‌شده)

| # | قابلیت | دستور |
|---|---|---|
| ۱ | ثبت یادداشت با عنوان، متن، برچسب و تاریخ شمسی | `add` |
| ۲ | فهرست‌بندی با فیلتر برچسب و نمایش بایگانی | `list [--tag] [--all]` |
| ۳ | نمایش کامل یک یادداشت | `show <id>` |
| ۴ | جستجو در عنوان، متن و برچسب | `search <عبارت>` |
| ۵ | ویرایش عنوان/متن | `edit <id> [--title] [--body]` |
| ۶ | سنجاق کردن یادداشت (نمایش در صدر فهرست) | `pin <id> [--off]` |
| ۷ | بایگانی و خروج از بایگانی | `archive <id> [--undo]` |
| ۸ | حذف با تایید تعاملی یا `--force` | `delete <id> [--force]` |
| ۹ | خروجی Markdown از همه‌ی یادداشت‌های فعال | `export <file>` |
| ۱۰ | آمار (کل، سنجاق، بایگانی، برچسب‌ها) | `stats` |
| ۱۱ | ورودی چندخطی تعاملی با پایان «.» | رفتار `add` بدون `--body` |

## ۳. طراحی فنی

- **زبان:** Python 3.8+، فقط کتابخانه‌ی استاندارد (`argparse`, `sqlite3`, `pathlib`, `datetime`)
- **پایگاه‌داده:** SQLite؛ جدول `notes(id, title, body, tag, created, pinned, archived)`؛ فایل `jsh.db` کنار پروژه
- **تاریخ:** تبدیل میلادی→شمسی با الگوریتم دقیق داخل `jsh.py` (تابع `gregorian_to_jalali`)، آزموده روی نوروز ۱۴۰۰–۱۴۰۵ و امروز (۱۴۰۵/۰۹/۰۴)
- **مرتب‌سازی فهرست:** سنجاق‌شده‌ها اول، سپس جدیدترین
- **مخزن:** https://github.com/kyanoosh27993/J.S.H

## ۴. تست‌ها

- تبدیل تاریخ شمسی: ۶ تاریخ مرجع، همه درست
- سناریوی کامل: add → list → search → pin → show → archive → list --all → stats → export → delete → stats؛ همه درست
