# J.S.H — پروژه «داشبورد تعمیرات و خدمات»

این مخزن، خانه رسمی پروژه **J.S.H** است. برنامه اصلی این پروژه، **«داشبورد تعمیرات و خدمات»** است: سامانه جامع مدیریت فروشگاه تعمیرات موبایل و لوازم الکتریکی برای ویندوز (نصب مستقل) + اپ اندروید متصل با بارکدخوان دوربین.

## وضعیت فعلی: مرحله طراحی (پیش از توسعه)

تمام نیازمندی‌ها طراحی و مستند شده‌اند و در انتظار تایید صاحب پروژه برای شروع توسعه هستند:

| سند / قلم | مسیر |
|---|---|
| گزارش کامل طراحی (Word + PDF) | `docs/dashboard/گزارش طراحی داشبورد تعمیرات و خدمات.docx` / `.pdf` |
| سند نیازمندی‌ها (درخواست‌های پیش‌فرض F-01 تا F-12 + پیشنهادهای S-01 تا S-20) | `docs/dashboard/REQUIREMENTS.md` |
| نقشه سیمکشی (معماری و روابط ماژول‌ها) | `docs/dashboard/charts/wiring_map.png` |
| جریان اصلی کسب‌وکار | `docs/dashboard/charts/business_flow.png` |
| نقشه راه شش‌فازه | `docs/dashboard/charts/roadmap.png` |
| لوگوی سازنده و آیکون‌ها (ICO ویندوز + mipmap اندروید + playstore) | `assets/logo/` |

## خلاصه برنامه در یک نگاه

- نصب مستقل روی ویندوز، کارکرد آفلاین‌محور با SQLite
- اپ اندروید متصل: ایجاد اطلاعات مثل رایانه + دوربین به‌جای بارکدخوان
- فرم‌های دیجیتال مطابق فرم‌های کاغذی فعلی فروشگاه (پذیرش، کارگاه، اقرارنامه تحویل)
- یادآوری ۳ روز قبل از تحویل + ایمیل PDF رسید + رویداد تقویمی روی گوشی
- CRM کامل، گارانتی اقلام با انتقال خودکار منقضی‌ها، داشبورد مدیریتی و پیش‌بینی درآمد
- لایسنس تجاری: فقط یک رایانه، حداکثر ۳ بار نصب، سپس پیام تماس با پشتیبانی
- فناوری پیشنهادی: Flutter برای ویندوز + اندروید با یک کدبیس

## گام بعدی

تایید سند طراحی توسط صاحب پروژه و اعلام شروع فاز ۱ (هسته ویندوز) طبق نقشه راه.

## برنامه جانبی موجود (نسخه قبلی مخزن)

دفترچه یادداشت خط فرمانی `src/jsh.py` از مرحله قبلی پروژه حفظ شده است:
`python src/jsh.py add «عنوان» --tag کار --body «متن»`
