# برنامه J.S.H

این مخزن، خانه‌ی رسمی پروژه‌ی **J.S.H** است. تمامی اطلاعات، مستندات و کدهای این پروژه طبق تصمیم صاحب پروژه در همین آدرس ثبت و نگهداری می‌شود.

## وضعیت فعلی

پروژه در مرحله‌ی آغازین قرار دارد و ساختار پایه در این مخزن ایجاد شده است:

```
J.S.H/
├── README.md          ← همین فایل (معرفی و مستندات پروژه)
├── src/
│   └── jsh.py         ← نقطه‌ی شروع برنامه
├── docs/
│   └── SPEC.md        ← مشخصات برنامه (در انتظار تکمیل)
└── .gitignore
```

## اجرای برنامه

پیش‌نیاز: Python 3.8 یا جدیدتر.

```bash
python src/jsh.py
```
