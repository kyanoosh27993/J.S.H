# J.S.H — پروژه «داشبورد تعمیرات و خدمات»

این مخزن، خانه رسمی پروژه **J.S.H** است. برنامه اصلی این پروژه، **«داشبورد تعمیرات و خدمات»** است: سامانه جامع مدیریت فروشگاه تعمیرات موبایل و لوازم الکتریکی برای ویندوز (نصب مستقل) + اپ اندروید متصل با بارکدخوان دوربین.

## وضعیت فعلی: مرحله طراحی (پیش از توسعه)

تمام نیازمندی‌ها طراحی و مستند شده‌اند و در انتظار تایید صاحب پروژه برای شروع توسعه هستند:

| سند / قلم | مسیر |
|---|---|
| گزارش کامل طراحی (Word + PDF) | `docs/dashboard/گزارش طراحی داشبورد تعمیرات و خدمات.docx` / `.pdf` |
| سند نیازمندی‌ها (درخواست‌های پیش‌فرض F-01 تا F-12 + پیشنهادهای S-01 تا S-20) | `docs/dashboard/REQUIREMENTS.md` |
| نقشه سیمکشی (معماری و روابط ماژول‌ها) | `docs/dashboard/charts/wiring_map.png` |
| جریان اصلی کسب‌وکار | `docs/dashboard/charts/business_flow.png` |
| نقشه راه شش‌فازه | `docs/dashboard/charts/roadmap.png` |
| لوگوی سازنده و آیکون‌ها (ICO ویندوز + mipmap اندروید + playstore) | `assets/logo/` |

## خلاصه برنامه در یک نگاه

- نصب مستقل روی ویندوز، کارکرد آفلاین‌محور با SQLite
- اپ اندروید متصل: ایجاد اطلاعات مثل رایانه + دوربین به‌جای بارکدخوان
- فرم‌های دیجیتال مطابق فرم‌های کاغذی فعلی فروشگاه (پذیرش، کارگاه، اقرارنامه تحویل)
- یادآوری ۳ روز قبل از تحویل + رویداد تقویمی روی گوشی (فایل ICS)
- CRM کامل، گارانتی اقلام با انتقال خودکار منقضی‌ها، داشبورد مدیریتی و پیش‌بینی درآمد
- لایسنس تجاری: فقط یک رایانه، حداکثر ۳ بار نصب، سپس پیام تماس با پشتیبانی
- فناوری پیشنهادی: Flutter برای ویندوز + اندروید با یک کدبیس

## گام بعدی

تایید سند طراحی توسط صاحب پروژه و اعلام شروع فاز ۱ (هسته ویندوز) طبق نقشه راه.

## برنامه جانبی موجود (نسخه قبلی مخزن)

دفترچه یادداشت خط فرمانی `src/jsh.py` از مرحله قبلی پروژه حفظ شده است:
`python src/jsh.py add «عنوان» --tag کار --body «متن»`

## برنامه تولید کد فعال‌سازی (مخصوص سازنده) 🗝️

برنامه جانبی مولد کد فعال‌سازی در `apps/license_gen/` قرار دارد و موتور مشترک آن در `packages/activation_core/`. **مستندات کامل برای تغییر دادن مستقل این برنامه:**

| سند | محتوا |
|---|---|
| [`apps/license_gen/README.md`](apps/license_gen/README.md) | معرفی، عملکرد، شروع سریع، جریان فعال‌سازی خریدار |
| [`docs/COMMANDS.md`](apps/license_gen/docs/COMMANDS.md) | **تمام دستورات لازم**: پیش‌نیاز، اجرا، تست، بیلد exe، انتشار، پشتیبان‌گیری، ابزار خط فرمان |
| [`docs/ARCHITECTURE.md`](apps/license_gen/docs/ARCHITECTURE.md) | نقشه فایل‌ها + دیاگرام معماری و جریان داده + مرز اشتراک با برنامه اصلی |
| [`docs/CODE_FORMAT.md`](apps/license_gen/docs/CODE_FORMAT.md) | فرمت کد فعال‌سازی بایت‌به‌بایت با مثال واقعی |
| [`docs/DATABASE.md`](apps/license_gen/docs/DATABASE.md) | بانک تاریخچه کدها، پشتیبان‌گیری، خروجی CSV، مهاجرت اسکیما |
| [`docs/CUSTOMIZATION.md`](apps/license_gen/docs/CUSTOMIZATION.md) | راهنمای گام‌به‌گام تغییرات (رنگ، متن، فیلدها، کلید امضا، قالب کد) + کارهای ممنوعه |
| [`docs/TROUBLESHOOTING.md`](apps/license_gen/docs/TROUBLESHOOTING.md) | عیب‌یابی کد کار نمی‌کند، بیلد، بانک و CSV |

ابزار خط‌فرمان تولید/بررسی کد (خودکارسازی): `dart run packages/activation_core/example/make_code.dart --device <شناسه> --expiry 1406/09/04`

## وضعیت توسعه: فاز ۱ در حال اجرا ✅

کد فاز ۱ (هسته ویندوز) در `apps/dashboard/` نوشته و اعتبارسنجی شد (`flutter analyze`: بدون خطا — `flutter test`: هر ۳ تست سبز):
- دروازه راه‌اندازی و گزارش نصب الزامی (N-03) — ذخیره محلی
- لایسنس تک‌رایانه‌ای با حداکثر ۳ نصب (F-09)
- ویزارد راه‌اندازی: اطلاعات فروشگاه و تنظیمات یادآوری ۲/۳/۷ روز توسط کاربر (N-01)
- پذیرش با فرم دیجیتال، امضا، PDF رسید (F-06, F-12)
- کارتابل کانبان، CRM مشتریان، یادآوری‌های مالی، صفحه پشتیبانی سازنده (N-02)

دستور ساخت روی ویندوز: `cd apps/dashboard && flutter pub get && flutter run -d windows`
