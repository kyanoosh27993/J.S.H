# برنامه J.S.H — دفترچه‌ی یادداشت شخصی

این مخزن، خانه‌ی رسمی پروژه‌ی **J.S.H** است. تمامی اطلاعات، مستندات و کدهای این پروژه طبق تصمیم صاحب پروژه در همین آدرس ثبت و نگهداری می‌شود.

## معرفی

J.S.H یک دفترچه‌ی یادداشت شخصیِ خط فرمانی است: ثبت، جستجو، ویرایش، سنجاق، بایگانی، حذف و خروجی گرفتن از یادداشت‌ها با پایگاه‌داده‌ی SQLite و تاریخ شمسی — بدون هیچ کتابخانه‌ی خارجی.

## ساختار پروژه

```
J.S.H/
├── README.md          ← معرفی و راهنمای استفاده
├── src/
│   └── jsh.py         ← برنامه‌ی کامل (خط فرمان)
├── docs/
│   └── SPEC.md        ← مشخصات فنی برنامه
└── .gitignore
```

پایگاه‌داده‌ی `jsh.db` در ریشه‌ی پروژه و هنگام اولین اجرا ساخته می‌شود (در `.gitignore` نادیده گرفته شده است).

## اجرا

پیش‌نیاز: Python 3.8 یا جدیدتر — هیچ وابستگی‌ای نصب نمی‌شود.

```bash
python src/jsh.py [دستور] [گزینه‌ها]
```

## دستورها

| دستور | کار | نمونه |
|---|---|---|
| `add` | ثبت یادداشت جدید | `python src/jsh.py add «قرار ملاقات» --tag کار --body «فردا ساعت ۱۰»` |
| `list` | فهرست یادداشت‌ها | `python src/jsh.py list --tag کار` یا `list --all` |
| `show` | نمایش کامل یک یادداشت | `python src/jsh.py show 3` |
| `search` | جستجو در عنوان/متن/برچسب | `python src/jsh.py search بودجه` |
| `edit` | ویرایش عنوان یا متن | `python src/jsh.py edit 3 --title «عنوان جدید»` |
| `pin` | سنجاق/برداشتن سنجاق | `python src/jsh.py pin 3` یا `pin 3 --off` |
| `archive` | بایگانی/خروج از بایگانی | `python src/jsh.py archive 3` یا `archive 3 --undo` |
| `delete` | حذف (با تایید یا `--force`) | `python src/jsh.py delete 3 --force` |
| `export` | خروجی Markdown | `python src/jsh.py export notes.md` |
| `stats` | آمار خلاصه | `python src/jsh.py stats` |

اگر `--body` داده نشود یا `-` باشد، برنامه متن چندخطی را از ورودی می‌خواند و با خطی شامل فقط «.» پایان می‌پذیرد.

## تاریخ شمسی

تبدیل تاریخ میلادی به شمسی با الگوریتم دقیق (بر پایه‌ی تقویم جلالی) داخل خود برنامه پیاده شده و با تاریخ‌های مرجع (نوروز ۱۴۰۰ تا ۱۴۰۵) آزموده شده است؛ مثلاً ۲۰۲۶/۱۱/۲۵ = **۱۴۰۵/۰۹/۰۴**.
